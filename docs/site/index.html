Smart CPR Training & Assessment System

Low-Cost • Local-First • Real-Time Objective Analytics • Explainable Feedback

ResQ upgrades conventional training manikins using a sensor-equipped chest overlay, embedded firmware, and a Windows LocalHub desktop application. It measures CPR performance in real time and provides immediate, rule-based feedback to both trainees and instructors without requiring internet access.

Learn About the Project View Specifications

Key Features

Retrofit Manikin Overlay

Fits onto existing training manikins, eliminating the need for expensive new smart manikins.

Real-Time Metrics

Live depth (mm), rate (cpm), full chest recoil, pause/interruption tracking, and hand-placement balance.

Multi-Manikin Dashboard

Supervise connection health, readiness, and live performance of multiple manikins simultaneously.

Local-First Operation

Embedded MQTT broker, backend, and database run locally on Windows. Training continues completely offline.

Guided Calibration

Pre-session checks verify zero rest position, sensor stability, reference pressure, and balance before scoring.

Session Review & Export

Automatic local storage with detailed post-session reviews, performance scoring, and CSV/JSON data export.

1. Sensor-Equipped Overlay

Pressure-sensitive TPU air-bladder structure and Hall-effect sensor capture displacement, force, and balance.

2. ESP32-C3 Controller

Processes sensor data, manages non-volatile calibration config, calculates live metrics, and broadcasts telemetry over local MQTT.

3. Windows LocalHub (Tauri)

Supervises local Spring Boot backend, embedded MQTT broker, and local SQLite database in a one-click desktop app.

4. Dashboards & Exports

Web-based instructor and trainee dashboards with live graphs, rule-based scoring, coaching tips, and CSV/JSON output.

Benefiting Entities

Medical & Nursing Education

University departments and healthcare schools needing objective competency verification.

CPR Skills Laboratories

Dedicated training labs requiring concurrent supervision of multiple practice stations.

First-Aid & Emergency Responders

Vocational centers and emergency service teams training responders to meet strict AHA standards.

Community & Outreach Camps

Large-scale field training programs benefiting from offline, highly portable local setups.
