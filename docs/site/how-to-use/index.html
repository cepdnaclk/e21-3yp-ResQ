How to Use ResQ

User guide for the ResQ CPR Training Overlay and LocalHub

Training use only: ResQ supports CPR education on a training manikin. It must not be used for patient care, diagnosis, treatment, or emergency decision-making.

System Requirements

Hardware & Infrastructure Needed

  • Training manikin fitted with the ResQ overlay
  • ResQ ESP32-C3 controller with power connection
  • Windows PC with ResQ LocalHub installed
  • Local Wi-Fi router or reliable mobile hotspot (no internet required)
  • Trainee display device (tablet, laptop, or monitor) connected to the local network

User Roles & Access Permissions

Administrator

Manage accounts, system roles, platform settings, connected hardware, and compliance audit logs.

Instructor

Pair manikins, run calibration checks, manage live training sessions, provide coaching, and export reports.

Trainee

Perform compression practice, monitor real-time visual feedback, and review personal performance history.

Technician

Run hardware diagnostics, perform sensor calibration, configure local Wi-Fi, and perform maintenance.

Viewer / Evaluator

Access assigned performance dashboards and review session analytics without modifying configuration.

Initial Setup & System Initialization

1

Inspect Equipment

Ensure the overlay is securely strapped, check the TPU bladder for leaks, inspect sensor wiring, and verify that the Hall-effect sensor and magnet are aligned with the chest unloaded.

2

Start ResQ LocalHub

Launch ResQ LocalHub on the instructor's Windows PC. Click Start Services and confirm that the MQTT Broker, Backend, and Dashboard service display Healthy/Running status.

3

Power Controller

Connect power to the ESP32-C3 controller. Ensure SENSOR mode is active for normal training operations (USB mode is reserved for diagnostics).

4

Network Pairing

If unconfigured, open Add/Pair Manikin in LocalHub, scan the device QR code, connect to the setup Wi-Fi, and save local network credentials to pair the device.

5

Run Pre-Session Calibration

In the Instructor Dashboard, select Run Calibration with the chest completely unloaded. Follow prompts to verify baseline rest position $P_0$, recoil, and pressure balance.

Operational Workflows

Instructor Workflow

  1. Verify manikin status is Online and Calibrated in LocalHub.
  2. Select trainee profile and target performance standard (e.g., AHA Adult).
  3. Click Start Session to initiate active telemetry and buzzer metronome (110 cpm).
  4. Monitor live compression rate, depth, recoil, pause time, and balance metrics.
  5. Click Stop Session upon completion, enter coaching feedback, and export CSV/JSON reports.

Trainee Workflow

  1. Position yourself at the manikin once the instructor confirms calibration is complete.
  2. Deliver compressions aiming for target depth (50–60 mm) and rate (100–120 cpm).
  3. Observe live dashboard visual feedback to correct posture, depth, or speed.
  4. Ensure full chest recoil between compressions without leaning on the overlay.
  5. Review post-practice score summaries to identify areas for skill improvement.

Hardware Reference Guide

LED Status Indicators

State LED Activity LED Status & Action
ON OFF Connected but uncalibrated → Run Calibration
OFF ON Ready for Session → Start from LocalHub
ON ON Session Active → Perform CPR & Monitor
ON Medium Blink Calibration Running → Follow on-screen instructions
ON Fast Blink Calibration Failed / Interrupted → Check load and retry
Fast Blink Fast Blink Firmware Fault → Reset controller or contact technician

Device Control Buttons

  • Button 1 (Short Press): Retry or resume recoverable operations.
  • Button 2 (Short Press): Cancel, clear prompt, or return to idle state.
  • Button 1 (Long Press >3s): Safely power down device into software off mode.
  • Button 2 (Long Press >3s): Perform factory reset and re-enter network setup mode.

Troubleshooting & Recovery

❌ LocalHub Services Fail to Start

Fix: Close any duplicate instances of LocalHub in Windows Task Manager, check for local port conflicts, restart the desktop application, and select Start Services again.

❌ Manikin Appears Offline

Fix: Verify controller power supply, confirm PC and controller are on the same local Wi-Fi router subnet, and re-check MQTT connection status in LocalHub.

❌ Calibration Repeatedly Fails

Fix: Ensure no external pressure or hands are resting on the chest overlay, inspect Hall sensor alignment (~5mm gap), verify air bladder seating, and retry pre-check.

❌ Unexpected Session Disconnection

Fix: Check power cable stability and local Wi-Fi signal. Restore connection—LocalHub automatically flags partial session records so you can safely recalibrate and resume.
